# 🚗 Car Wash - Auto Spa & Detailing Management System

Full-stack car wash & auto detailing enterprise management web application built with **Node.js, Express, MongoDB Atlas, Vite, React & Vanilla CSS**.

## 🌟 Key Features
- **Hero & Services**: 12 detailing services with high-pressure foam, ceramic coating, steam sanitization.
- **3-Tier Packages**: Transparent pricing matrix for Sedan, SUV, Luxury vehicles.
- **4-Step Booking Wizard**: Slot booking, vehicle selection, coupon application & online UPI/Card payment with digital invoice generation.
- **Live Bay Tracker**: 6-stage real-time progress tracker with tracking code lookup (`CW-8921`).
- **Owner Enterprise Dashboard (`#admin`)**: Dedicated sidebar dashboard for revenue vs expenses profit metrics, live bay control, CRM, staff management & abandoned lead recovery.
- **Customer Rewards & Coupons**: Mobile number / Vehicle reg lookup for loyalty points, coupons, and referral link sharing via WhatsApp.

## 🚀 Quick Start

### 1. Server (Backend API)
```bash
cd server
npm install
npm run dev
```

### 2. Client (Vite React Frontend)
```bash
cd client
npm install
npm run dev
```
